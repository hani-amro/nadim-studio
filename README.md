# Nadim Studio

A front-end demo by [Hani Amro](https://hani-amro.github.io/); Nadim Studio is an invented artist, the paintings are generated graphics, and nothing here is for sale.

- A gallery page with an interactive canvas
- A scroll-driven 3D museum walk
- A WebGL sculpture room

Stack: React 19, Vite 8, TypeScript 5.9, Tailwind 4, react-router-dom 7, three 0.185.

## Run

```bash
cd web
npm install
npm run dev      # dev server
npm run build    # production build into web/dist
```
